Born from the frustration of repeatedly typing local IP addresses and scanning blurry QR codes while testing responsive mobile viewports.

01 / INGRESS

Chrome Extension (MV3)

Single-click toolbar push and global hotkey triggers. Automatically inspects active browser tabs and translates loopback addresses (`127.0.0.1` / `localhost`) into your machine's broadcastable LAN IP address.

Manifest V3 Service Worker IP Resolver
02 / INFRASTRUCTURE

Dockerized Relay Hub

Ultra-lightweight Node.js WebSocket relay server packaged into an alpine container. Operates seamlessly on local homelabs or remote VPS instances, exposed securely via Cloudflare Tunnel without port-forwarding headaches.

Docker Cloudflare Tunnel WebSockets
03 / HARDWARE SHELL

Mobile PWA + Wake Lock

Progressive Web App receiver running on your mobile phone on a desk dock. Utilizes the Screen Wake Lock API and background keep-alive audio so your screen never goes dark during intense coding sessions.
